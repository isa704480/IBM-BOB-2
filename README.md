# PatchPilot 🛠️

**Agentic dependency-upgrade autopilot — built with IBM Bob 2.0.**

> Dependabot bumps a version and walks away. **PatchPilot** fixes the breaking changes across
> your whole repo, verifies them, and produces a merge-ready result.

Built for the **IBM Bob 2.0 Hackathon**.

---

## The problem

Automated dependency PRs (Dependabot/Renovate) only change the version number — they don't fix
the code the new version breaks. So those PRs pile up unmerged, security patches lag, and every
major upgrade eats hours of manual work.

## The solution

PatchPilot runs the whole upgrade as an agentic pipeline:

```
copy repo → naive upgrade → map impact → load migration rules
→ parallel subagents fix every breaking change → verify (green) → report + PR
```

- 🧠 **Full-repo context** — maps every call-site of the dependency
- 📄 **Document understanding** — turns a CHANGELOG/migration guide into migration rules
- ⚡ **Parallel subagents** — one per module, fixed concurrently
- ✅ **Verified** — ends on a green build or an honest `needs_bob` flag (never faked green)

## Proven result (Express 4 → 5, sample-monorepo)

| | Before | After |
|---|---|---|
| Build | ❌ 3 services crash at load | ✅ green |
| Tests | 0 passing | **11 / 11 passing** |
| Fixes | — | 6 across 3 services |
| Cost (via Bob) | — | **~1.41 Bobcoins** |

See [HOW_BOB_WAS_USED.md](HOW_BOB_WAS_USED.md). In short: Bob (Agent mode) read the repo,
