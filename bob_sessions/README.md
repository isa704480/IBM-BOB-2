# bob_sessions/

> **MAJBURIY deliverable.** Bu papkada IBM Bob'ning **task session summary screenshotlari**
> saqlanadi — Bob'dan foydalanganingizning isboti. (Rasmiy Hackathon Guide talabi.)

## Nima solinadi
Har bir loyihaga aloqador Bob task uchun **session consumption summary** screenshoti (PNG).
**Har bir jamoa a'zosi** o'z tasklarini yuklaydi.

## Screenshotni qanday olish (Bob IDE)
1. Bob IDE chat interfeysida **Tasks** ni oching.
2. Loyihaga aloqador **task**ni tanlang (bir nechta workspace bo'lsa — **All**).
3. **Task header**ni bosing → *task session consumption summary* chiqadi.
4. Screenshot oling (matn aniq bo'lishi uchun **PNG**).
5. Har task uchun takrorlang.

## Nomlash qoidasi
```
<jamoa>_task<NN>_<qisqa-tavsif>_summary.png
```
Namuna:
- `fayzinc_task01_impact_map_summary.png`
- `fayzinc_task02_subagent_remediation_summary.png`
- `fayzinc_task03_pr_migration_notes_summary.png`
